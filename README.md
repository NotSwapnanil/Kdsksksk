# CM Tuition Classes — Complete Deployment Package

This standalone package contains the complete production-ready website for **CM Tuition Classes**.

## Features Included:
- **Zero External Dependencies**: Works online or 100% offline.
- **Embedded Media**: All 26 classroom gallery photos, 8 videos, handwritten schedule sheets, and 15 teacher profiles with photos are fully connected.
- **Interactive UI**: Working branch switcher, touch-enabled gallery slider, video testimonial modals with direct play, routine rotation controls, FAQ accordion, and inquiry form.
- **Instant Hosting Ready**: Includes configurations for Netlify (`netlify.toml`, `_redirects`) and Vercel (`vercel.json`).

## How to Deploy:
1. **Netlify Drop (Easiest)**: Drag and drop the `cm_tuition_deploy` folder or `cm_tuition_deploy.zip` directly into [app.netlify.com/drop](https://app.netlify.com/drop).
2. **Vercel / GitHub Pages / Cloudflare Pages**: Connect your repository or upload the contents of this folder directly.
3. **Traditional Web Hosting (cPanel / Hostinger / GoDaddy)**: Upload all files to your `public_html` directory.
4. **Local / Offline**: Open `index.html` directly in any browser on Android, iPhone, Mac, Windows, or Linux.
